A full-stack social media web application inspired by Facebook. This project demonstrates proficiency in modern web development, featuring a responsive UI, user authentication, dynamic post creation, and an interactive news feed.

---

## ✨ Features

* **User Authentication:** Secure signup and login functionality.
* **News Feed:** A dynamic, real-time feed displaying posts from users.
* **Post Creation:** Users can create posts with text and image uploads.
* **Interactive UI:** Ability to like and comment on posts seamlessly.
* **Responsive Design:** Optimized for both desktop and mobile viewing, mimicking the classic social media layout.

---

## 🛠️ Tech Stack

**Frontend**
* React.js
* Context API (State Management)
* CSS / Styled Components

**Backend**
* Node.js & Express.js
* MongoDB & Mongoose (Database)
* JSON Web Tokens (JWT) for Authentication

---

## 🚀 Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites
* Node.js installed on your local machine
* MongoDB instance (Local or Atlas)

### Installation

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/anuj-1104/Facebook_Clone.git](https://github.com/anuj-1104/Facebook_Clone.git)
   cd Facebook_Clone

Setup the Backend:

Bash
cd server
npm install
Create a .env file in the server directory:

Code snippet
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
Start the backend server:

Bash
npm start
Setup the Frontend:

Bash
cd ../client
npm install
Start the React application:

Bash
npm start
